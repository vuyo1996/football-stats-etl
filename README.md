# Football Stats ETL Project

This project cleans and transforms football statistics data using pandas and PostgreSQL.

## Technologies Used

- Python
- pandas
- PostgreSQL
- SQL
- Jupyter Notebook

## Project Workflow

Raw football data → pandas cleaning → PostgreSQL database → SQL analysis

## Analysis Examples

- Goals per shot
- Club attacking efficiency
- Duel win percentage
- Goalkeeper clean sheet analysis

## Files

- `football_stats_analysis.ipynb` — main notebook containing cleaning, transformation, and analysis
